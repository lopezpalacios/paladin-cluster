Paladin · LFDT · lopezpalacios/paladin-cluster

Public parts. Private parts.
Two devices, one notary that cannot lie alone.

One chain. Some transactions fully readable on the explorer. Others exist only as a hash on-chain and real data between the member nodes. A 2-of-2 signing module so neither device can sign without the other. Run any example in one command.

sepoliakind + besupentenotozeto + KYC2-of-2 cosign API

The idea

Public section

Everything readable on the chain

ERC20 balances, KYC registrations, plain deploys. Real data in real blocks. Visible on the explorer by anyone.

Private section

Only a hash on the chain

Pente groups and Zeto proofs. Amounts and parties live only in member state stores. The chain sees a commitment and a valid proof.

Two-device control

Neither notary signs alone

A signing module in each node calls the other device's cosigner API before the local key may sign. One side offline = frozen.

Examples

examples/hello-vlad

HelloVlad

Compile your own hello-vlad.sol with solc, deploy publicly on Sepolia, call sayHello, verify the event.

npm run compile && npm run start

examples/storage-vlad

StorageVlad

Public store of a string + uint256 on Sepolia. "i send vlad 8152 chf". Readable by everyone on etherscan.

npm run compile && npm run start

examples/pente-group

Private contract in a group

Privacy group of node1+node2, private deploy, private store, node3 outsider gets "group not found".

npm run start

examples/noto-token

Notarized tokens

Mint, transfer, burn with a notary. Receipt visibility: notary sees all, receiver sees only its own coin.

npm run start · npx ts-node src/burn.ts

examples/private-stablecoin

Private stablecoin with KYC

Public ERC20 + private Zeto, deposit/withdraw bridge, ZK transfers with KYC. The public/private split, complete.

in paladin repo: examples/private-stablecoin

examples/notary-2of2

Two-device co-signed notary

Cosigner API on each device. Approval, policy rejection, and freeze-when-peer-down. Demonstrated with curl.

./demo.sh

Two devices, quickstart

git clone https://github.com/lopezpalacios/paladin-cluster.git && cd paladin-cluster
./install-tools.sh && ./start-paladin.sh # or: nix develop && ./start-paladin.sh

Each device runs its own stack. The cosigner API (port 9191) pairs them. API spec.
